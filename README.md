# Gentle forced aligner HTML modification script

This is a simple Python script to modify files output by the [Gentle forced aligner](https://github.com/strob/gentle) software.
Files output by the script contain small adjustments to the embedded JavaScript that will cause the audio to jump to and pause when a word in
the transcript is clicked rather than continuing forward from that word immediately after jumping. The script intends to aid in getting
accurate timestamps more easily from a Gentle HTML file. An extra box with the audio's timestamp *that can be copy-pasted from* is also added.

## Dependencies
- Python 3.8 or higher
- Typer (can be easily installed with `pip install typer`)
- An already-generated html file from the Gentle forced aligner

## Installation / Download
- Simply clone the respository via git. No installation is needed.

## Use of script
- Place the HTML file generated by Gentle in the `files` directory, along with the audio and transcript files used to generate it.
- Call the script from the command line as follows (Note that the exact command to call Python may vary depending on your
OS / distribution / etc. (`python` vs `python3`)):
    `python convert.py "files/path to your gentle html.html"`
- If there are no spaces in the filename, you may omit the quotation marks. As follows:
    `python convert.py files/path_to_your_gentle_html.html`
- The output file will be named `<initial file name>_parsed.html` and will automatically be placed within the `files` directory. For example, if your file was
named `index.html`, the new file wil be named `index_parsed.html`.

## Use of parsed files
- Click on a word to jump the audio forward to that word. The audio will pause. When resumed, it will continue from the beginning of the selected word.
- The timestamp in the dark grey box can be copy-pasted. Because of the way in which it needed to be laid atop the existing HTML with as few lines of code
inserted as possible, you will need to drag your mouse cursor diagonally across the text to select it rather than horizontally. Please see the embedded video
